D-Blockerz Privacy Policy

Effective date: October 7, 2026

D-Blockerz is a privacy-focused Microsoft Edge extension that blocks advertising, tracking, and analytics network requests.

1. Information D-Blockerz accesses

D-Blockerz accesses limited information necessary for its functionality.

  • Current website hostname: D-Blockerz reads the URL of the active Microsoft Edge tab to determine the current website. This allows the extension to display the current website and provide controls to pause or resume protection for that website.
  • Extension settings: D-Blockerz stores protection state, whitelist domains, and filter-list settings locally in Microsoft Edge extension storage.
  • Local statistics: D-Blockerz may store blocking statistics locally in Microsoft Edge extension storage.

2. How information is used

Information accessed by D-Blockerz is used only to provide the extension's privacy and blocking functionality.

The active website hostname is used locally to identify the website currently being viewed and to provide the site's protection controls.

Extension settings and statistics are used to preserve the user's preferences and display information in the extension.

3. Network request processing

D-Blockerz uses Microsoft Edge's declarativeNetRequest functionality to evaluate network requests against blocking rules.

Requests matching advertising, tracking, or analytics rules may be blocked. Requests for websites added to the user's whitelist may be allowed.

D-Blockerz does not send browsing history, network request URLs, page contents, or network request data to a server operated by the developer.

4. Data storage

D-Blockerz uses Microsoft Edge extension storage to keep extension settings and locally generated statistics.

This information remains on the user's device and is not transmitted to the developer by D-Blockerz.

5. Data sharing

D-Blockerz does not sell, rent, license, or share user data with third parties.

D-Blockerz does not use third-party analytics, advertising, tracking, or telemetry services.

6. Remote code

D-Blockerz does not use remote code. The extension's executable JavaScript and application logic are included in the extension package and are not loaded from remote servers.

7. User controls

Users can enable or disable protection, add or remove websites from the whitelist, enable or disable filter lists, and reset locally stored blocking statistics through the extension.

Users can also remove D-Blockerz from Microsoft Edge through the browser's extension management interface.

8. Data retention

D-Blockerz retains extension settings and locally stored statistics only for as long as they remain in the user's Microsoft Edge extension storage.

D-Blockerz does not maintain a server-side database of user browsing activity.

9. Third-party services

D-Blockerz does not send user data to third-party services.

Microsoft Edge and the Microsoft Edge Add-ons service may independently process information associated with extension installation, updates, store usage, reviews, or browser operation under Microsoft's own policies. D-Blockerz does not control that processing.

10. Security

D-Blockerz is designed to minimize access to user information and process extension data locally whenever possible.

11. Changes to this privacy policy

This privacy policy may be updated when D-Blockerz gains new features or changes how information is handled. The effective date at the top of this page will be updated when material changes are made.
